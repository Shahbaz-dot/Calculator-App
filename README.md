# Calculator-App
A simple and user-friendly calculator application for performing basic mathematical operations.


## ✨ Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Simple and easy-to-use interface

## 🛠️ Technologies Used
- HTML / CSS / JavaScript

## 🚀 How to Use
1. Clone this repository.
2. Open the project in your preferred editor.
3. Run the application.
4. Start performing calculations.
